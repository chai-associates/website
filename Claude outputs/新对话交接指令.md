## 3. 品牌语法 8 条（已锁定，写在 tokens.css 开头）

1. 圆角：卡片、照片 12px；栏位 8px
2. 按钮一律胶囊形，可以换行（长名字不会撑出画面）
3. 英文版的 h1、h2 用 Garamond 衬线；中文标题、h3 以下用无衬线（英文页里的中文字会自动用 Noto Sans SC）
4. 灰色区块 = 换话题；细横线标题（`.list-head`）= 一组清单的开头
5. 小标签（`.tag`）：大写、拉开字距、古铜色
6. 照片比例：人像 4:5，场景 3:2（写在积木本身）
7. 古铜色只用在主要按钮和小标签
8. 动态要轻（`--motion` / `--ease`；`.reveal` 往下滑时浮现）；手机设定「减少动态」时全部关闭

其他定案：
- 按钮文字一律用动词（页首的「咨询 / Enquire」除外）。
- 没有斜体。
- 手机不做固定在底部的咨询按钮，也没有悬浮按钮。
- 中文句子里，名字前后不加空格。

**积木清单：** container、section（同色相连共用一个间距）、section-muted、section-head、page-head、profile-head、list-head、stack、prose、with-aside（侧栏本身就是卡片）、cta-band（深色，一个主要按钮，可再加一个文字链接）、btn / btn-cta / btn-outline / btn-ghost / btn-light / btn-sm、btn-row、text-link、chip（`aria-pressed` 会变黑）、tabs、card / card-link、card-grid、photo-card、photo-frame、person-grid（手机 2 栏、电脑 4 栏）、person-card、person-photo、facts、rule-list（项目可以是「h3 + p」）、breadcrumb、field、select、scroll-row、reveal。
